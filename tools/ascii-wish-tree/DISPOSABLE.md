## Result

“올해는 대충 살아도 잘 풀리게 해주세요”를 입력하면 그 문장이 트리 표면의 글자가 된다. 트리는 천천히 회전하고 여러 색 글자·금색 가랜드·선물·별 사이로 흰빛이 반짝인다. 내 소원을 찾으면 해당 글자가 정면으로 돌아와 한 줄 또는 짧은 여러 줄로 펴지고, 밝게 확대된다.

공유 링크를 열면 해당 소원이 즉시 반짝이고, “내 소원도 입력하러 가기”를 누르면 입력 화면으로 넘어간다.

실제 사용 예시는 위 live 주소에서 볼 수 있다. 이 폴더는 트리 제작 지침만 제공하는 레시피이며 실행 프로그램·글꼴·브랜드 에셋은 포함하지 않는다.

## Before you start

웹 코드를 만드는 AI 도구와 Canvas 2D를 지원하는 브라우저가 필요하다. 한글은 시스템 글꼴로 시작하고, 별도 글꼴을 쓰면 재배포 허용 조건을 확인한다.

소원 입력과 회전을 로컬에서 먼저 만든다. 방문자 모두의 소원을 공유하려면 저장 서버를 별도로 연결한다. AI 도구와 서버의 비용·한도는 선택한 환경에서 확인한다.

## Quick start

1. 아래 Rebuild 전체를 자신의 AI 도구에 건네고, 우선 샘플 소원을 쓰는 로컬 웹 시안을 만든다.
2. 소원을 적고 찾기·회전·공유 링크를 확인한다. 흰 반짝임이 글자를 가리지 않는지 휴대폰 폭에서도 본다.
3. 공개 서비스가 필요하면 공유 저장소를 연결하고 실제 주소에서 다른 방문자의 소원도 조회되는지 확인한다.

## Rebuild

다음 사양으로 브라우저의 Canvas 2D만 쓰는 ASCII 소원 트리를 만들어 줘. 외부 트리 소스 코드를 가져오지 말고 새로 구현해 줘. 파일은 렌더러, 소원 데이터, 입력 화면으로 나눠 줘.

### 소원 데이터와 글자

- 소원 데이터는 `{ id, text }` 목록이다. 40자까지 받고 `Intl.Segmenter`의 grapheme 단위로 센다. 없는 환경에서는 `Array.from`으로 대체한다. 공백을 정리하고 줄바꿈·제어 문자·양방향 제어 문자는 제거한다.
- 입력 문장은 HTML로 넣지 않는다. 화면 글자는 `textContent`, 트리는 Canvas `fillText`로 그린다.
- 소원 내용은 밝기에 따라 다른 문자로 바꾸지 않는다. 원래 문장을 유지하고 글자 색의 밝기로 입체감을 낸다. 공백은 가운데점으로 표현해도 된다.
- 소원이 적으면 각 소원을 최대 세 번 반복하고 나머지는 “소원을 적어 주세요”, “새해 복 많이 받으세요” 같은 안내 글자로 채운다. 이 안내와 샘플을 실제 참여 수로 집계하지 않는다.
- 소원이 넘치면 최근 소원을 우선 담되 지금 찾는 소원과 이 브라우저의 최근 소원은 항상 포함한다.

### 트리 모양과 회전

- 트리를 높이 방향의 여러 수평 링으로 나눈 회전체로 만든다. 각 링의 둘레에 소원 글자를 순서대로 배치한다. 가로 셀 간격은 화면 크기에 맞춰 9~16px, 세로 간격은 그 값의 약 1.12배로 시작한다.
- 높이 비율 `u`는 꼭대기 0, 밑동 1이다. 층 경계는 `[0, 0.2, 0.42, 0.68, 1]`로 둔다. 바깥 윤곽은 `E(u)=0.18+0.82*u`다.
- 해당 층의 시작과 끝을 `a,b`, 진행률을 `k=(u-a)/(b-a)`라 하자. 층의 위쪽 반지름은 첫 층이면 0.03, 나머지는 `E(a)*0.45`다. 이 값과 `E(b)`를 `k^0.85`로 보간해 가지 층을 만든다.
- 각 링의 최대 반지름은 화면 폭과 트리 높이 안에 들어오게 정하고, 문자 수는 대략 `ceil(2πr)`로 잡는다. 링마다 시작 각도를 조금씩 다르게 한다.
- 링 위 각도와 회전 각도의 합을 `angle`이라 할 때, 화면 가로 위치는 `cx+r*sin(angle)`, 세로 위치는 `treeTop+ringIndex+0.1*r*cos(angle)`, 깊이는 `r*cos(angle)`로 계산한다.
- 같은 셀에 글자가 겹치면 깊이가 큰 글자만 남기는 z-buffer를 쓴다. 뒤쪽 글자는 생략하고 광원 방향과 표면 방향의 내적으로 밝기를 조절한다.
- 자동 회전은 약 0.32rad/s로 시작한다. 포인터로 끌면 회전 각도를 바꾸고, 놓으면 관성이 줄어든 뒤 약 1.5초에 걸쳐 자동 회전으로 돌아오게 한다.

### 여러 색과 흰 반짝임

- 잎 글자는 초록, 가랜드는 금색으로 둔다. 빨강·파랑·보라·분홍·청록 장식과 전구를 드문드문 섞고 밑동에는 문자로 만든 선물, 꼭대기에는 별을 놓는다.
- 전체 글로우는 캔버스를 1/4과 1/12 크기로 줄였다 다시 확대해 `lighter` 합성한다. 여러 색 테마의 합성 알파는 각각 0.26·0.34로 시작한다. 트리 영역의 클립을 복원한 뒤 전체 글로우를 합성해 배경에 띠가 생기지 않게 한다.
- 표면 60곳을 고정 난수 시드로 고른다. 점마다 2.8~5.2초의 다른 주기와 0.65~1.15초의 켜짐 시간을 준다. 펄스는 `sin(π*진행률)^1.3`이다. 동시에 모두 번쩍이지 않게 시작 시점을 어긋나게 한다.
- 흰 별은 작은 것 1.6셀, 큰 것 2.8셀 정도로 그린다. 일부 큰 점에는 길이 3.8셀의 가느다란 십자 광선을 섞는다. 빛의 중심은 또렷하게 둔다.
- 별 뒤에는 반지름 2.8셀 또는 4.2셀의 원형 그라데이션을 그린다. 중심은 옅은 흰색·차가운 흰빛, 바깥은 투명이다. 별의 그림자 번짐은 각각 3셀·4.6셀로 시작한다.
- 반짝임의 위치도 트리와 같은 링·각도로 계산한다. 앞쪽 표면이며 z-buffer에서 가려지지 않은 위치에만 그린다. 트리가 회전할 때 빛이 공중에 고정되지 않게 한다.
- 내 소원을 찾는 동안 주변 반짝임 밝기는 82% 줄인다. `prefers-reduced-motion`에서는 회전과 반짝임을 멈추고 일부 고정 하이라이트만 남긴다.

### 내 소원 찾기와 공유

- 소원이 배치된 링·각도를 ID와 함께 기록한다. 찾기를 누르면 그 소원의 중간 글자가 정면을 향하도록 회전한다. 문장을 읽기 좋게 한 줄 또는 짧은 여러 줄로 펴고 주변은 어둡게, 해당 문장은 흰 금색으로 밝게 한다.
- 일반 입력 뒤 찾기에는 약 1.5초 회전 전환과 확대를 쓴다. 일반 화면에서는 입력창, 소원이 있는 상태에서는 찾기 버튼을 보여 준다.
- 공유 주소는 트리 주소 뒤에 `?w=소원번호`를 붙인다. 공유 링크에서는 일반 성장 애니메이션을 기다리거나 입력창을 먼저 보여 주지 않는다. 데이터가 도착하면 해당 소원을 정면·확대·반짝임 상태로 즉시 연다.
- 이때 첫 렌더 전에 선택 문장의 화면 중심과 확대 기준점을 계산해 둔다. 기준점이 0인 상태로 확대해 문장이 화면 밖으로 나가지 않게 한다.
- 다른 사람의 소원을 보는 화면에는 “내 소원도 입력하러 가기”와 링크 복사를 둔다. 입력 버튼을 누르면 공유 번호를 주소에서 빼고 트리 회전을 풀며 입력창에 포커스한다.
- 존재하지 않는 번호는 조용히 다른 소원으로 바꾸지 말고 찾을 수 없다고 안내한다. 서버 오류에는 재시도 수단을 주고 가짜 데이터로 바꿔 성공한 것처럼 보이지 않게 한다.

### 공유 저장이 필요할 때

- 로컬 시안은 샘플 목록과 브라우저 저장만으로 확인할 수 있다. 여러 방문자의 소원을 하나의 트리에 모으려면 서버 저장으로 바꿔야 한다.
- 서버에 ID·소원 문장·작성 시각을 저장하고 브라우저에는 내 소원 번호만 기억한다. 새 방문자도 같은 ID로 같은 소원을 읽을 수 있어야 한다.
- 예시 구조는 정적 페이지 + Worker API + 전용 D1이다. 최근 400개는 60초 캐시하고, 캐시에 없는 오래된 내 소원·공유 소원은 ID로 따로 조회한다. 실제 전체 개수는 집계 테이블로 관리한다.
- 서버에서도 같은 40자 검증을 한다. 쓰기는 같은 출처의 JSON 요청으로 받고, 과도한 입력을 제한한다. 시작값은 네트워크당 쓰기 5회/분·읽기 120회/분이며, 위치별 제한과 별도로 DB에서 전역 하루 3,000개 신규 소원 상한을 둘 수 있다.
- 샘플 데이터는 공개 DB에 넣지 않는다. 배포 전에 로컬 저장·공유 저장을 구분하고, 공개 뒤 임시 검수 소원은 그 ID와 문구가 정확히 일치하는 한 건만 지운다.

### 확인할 것

- 390px 폭과 넓은 화면에서 소원 입력·회전·찾기·다시 입력이 동작한다.
- 40자를 넘는 소원이 클라이언트와 서버에서 거부되고, HTML처럼 생긴 입력도 글자로만 보인다.
- 내 소원 번호가 없는 상태로 공유 링크를 열어도 같은 소원이 바로 보인다. 그 전에 입력창이 잠깐 나타나지 않는다.
- 흰 반짝임이 트리 표면을 따라 움직이고 선택 문장을 가리지 않는다. 동작 줄이기에서는 화면이 움직이지 않는다.
- 서버를 쓰면 다른 방문자의 상태에서도 같은 ID 조회를 확인한다.

## Limits

이 레시피는 비슷한 트리 화면과 상호작용을 다시 만드는 사양이다. 같은 AI 요청만으로 완전히 같은 픽셀을 보장하지 않는다. 실제 제작에서 선택한 글꼴·난수·문구·색과 화면을 따로 보존하면 수정하기 쉽다.

브랜드 이미지·별도 글꼴의 사용 권리는 포함하지 않는다. 시각 형식은 @dwcminh.ascii의 ASCII Christmas Tree를 참고했지만 원본 코드는 포함하지 않았다. 자신의 콘텐츠에 맞는 문구·소원·그림을 사용한다.

지속적인 유지보수나 모든 브라우저·실기기의 동일한 성능을 약속하지 않는다. 공유 서버의 저장 한도·요청 제한·소원 관리 기준은 운영 환경에 맞게 정한다.
