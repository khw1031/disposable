# felt-sense-prompt

AI에게 보내려는 문장은 대개 그 사람이 아는 것의 일부다. 「분위기 좋은」「깔끔하게」 같은 말 뒤에는 보면 알지만 아직 말이 안 된 느낌(Felt Sense)이 있다. 이 스킬은 그 느낌이 **있다고** 가정할 뿐, 그 느낌이 **무엇인지**는 가정하지 않는다. 느낌을 아는 사람은 사용자뿐이므로 말은 사용자에게서 나와야 한다.

## 경계

- 불변식: 최종 프롬프트의 조건 말은 모두 사용자가 한 말이거나 사용자가 고른 후보다. AI가 낸 말은 사용자가 고르기 전까지 `[AI 후보]`를 달고, 최종본에는 말마다 출처를 남긴다. 조건을 이어 주기만 하는 말(「…같은 곳」「그런 일이 없게」)은 조건이 아니며 출처에 「조립 문구」로 적는다.
- 다듬은 프롬프트를 대화에 출력만 한다. 다른 AI에 보내거나, 요청을 실행하거나, 파일로 저장하지 않는다.
- TAE 공식 14단계 중 1~4단계만 쓴다. 원문과 출처는 참조 파일에 있다. 「말을 느낌에 대어 본다」는 Gendlin 소개문을 풀어 쓴 표현이며 TAE 용어가 아니다.
- 이 방법이 AI 답을 좋게 만든다는 직접 연구는 없다. 그렇게 약속하지 않는다.
- 사용자는 떠올린 장면을 자세히 밝히지 않아도 된다. 민감하면 「그런 순간 하나를 떠올렸다」만으로 진행한다.

## 흐름

기본 흐름은 사용자 답 두 번 안에 초안을, 세 번 안에 최종본을 낸다. 한 턴에 묻는 것은 밑줄 확인(예·아니오)과 질문 둘까지다. 2단계를 시작할 때 [references/tae-steps.md](references/tae-steps.md)를 열어 질문 문구와 출력 형식을 따른다.

1. **받기.** 문장을 받는다. 받았던 AI 답이 있으면 함께 받는다. 느낌이 걸릴 말이 없는 사실 요청(설치법·변환·계산)이면 「원하는 느낌이 따로 있나요?」를 한 번만 묻고, 없으면 원문을 그대로 돌려준다.
2. **밑줄과 순간(TAE 1·2단계).** 느낌을 가장 많이 실은 말 하나를 밑줄 후보로 보이고 맞는지 묻는다. 같은 턴에 두 가지를 묻는다: 그 느낌이 실제로 있었던 순간 하나, 앞뒤가 좀 안 맞아도 되는 문장 하나. 첫 「모르겠어」에는 순간 하나를 떠올리기만 하라고 한 번 더 청한다(밝히지 않아도 된다).
3. **다른 말(TAE 3단계).** 밑줄 말의 흔한 뜻은 버리고, 동의어가 아닌 둘째·셋째 말을 사용자에게 받는다. 막힐 때 쓸 `[AI 후보]`를 사용자의 순간과 문장에서만 뽑아 셋까지 같은 턴에 덧붙인다. 고르는 사람은 사용자다.
4. **초안과 각 말이 꺼내는 것(TAE 4단계).** 고른 말을 사용자의 표현 그대로 조건으로 삼아 원래 요청과 합친 초안을 최종본과 같은 형식으로 내고, 조건마다 출처를 단다. 두 가지로 읽히는 말(「하나」가 메시지인지 숫자인지)에는 「이 말로 무엇을 말하고 싶었나」를 같은 턴에 묻는다.
5. **대어 보기와 확정.** 조건과 넣은 장면, 밑줄 말을 하나씩 속으로 읽어 보게 한다. 「아, 그거」 하고 무언가 움직이는지는 사용자만 알므로, 사용자가 남기겠다는 조건만 남긴다. 4단계 질문의 답으로 조건을 고쳐 최종본을 낸다.

조립할 때 지킨다.

- 밑줄 말(원래 단어)은 사용자의 말이다. 사용자가 빼자고 하기 전에는 지우지 않는다.
- 떠올린 순간이 잘못된 장면이면(「표에서 길을 잃었다」) 「피하고 싶은 장면」으로 넣는다. 「…같은 곳」으로 바꿔 뜻을 뒤집지 않는다.
- 2단계 문장에서 조건이 되지 않은 말(「꽉 찬」)은 버리지 않고 「아직 말이 안 된 것」에 올린다.

예외: 사용자가 「질문 말고 바로」를 요청하면 한 번에 초안을 낸다. 이때 사용자 원문 밖의 말은 모두 `[AI 후보]`로 표시하고 「확정 전 초안」이라고 밝힌다. 재료가 원문뿐이라 후보는 흔한 뜻에서 나오므로 `[AI 후보 · 흔한 뜻]`으로 적는다. 밑줄 확인은 생략하고 2단계 질문 두 개만 붙인다.

## 실패 명세

| 신호 | 판정 | 할 일 |
|---|---|---|
| 최종본에 출처 없는 말이 있다 | 거짓 성공 | 그 말을 `[AI 후보]`로 되돌리고 사용자에게 묻는다 |
| 동의어로만 바뀌고 새로 정해진 조건이 없다(「깔끔하게」 → 「세련되고 군더더기 없이」) | 거짓 성공 | 「말만 바뀜」이라고 알리고 3·4단계로 돌아간다 |
| AI가 「이런 느낌이죠?」라며 장면이나 조건을 지어낸다 | 범위 위반 | 지운다. 느낌의 내용은 사용자에게서만 나온다 |
| 사실 조건(장소·인원·예산·기한 등)이 비어 있다 | TAE 밖 | 채우지 않는다. 「보내기 전 확인할 빈칸」에 질문으로만 남긴다 |
| 사용자가 「모르겠어」를 두 번 하거나 어떤 말도 맞지 않는다 | 기권 | 억지로 고르지 않는다. 원문, 떠올린 순간, 「아직 말이 안 된 것」을 돌려준다 |
| 느낌이 걸릴 데가 없는 사실 요청이다 | 범위 밖 | 1단계 확인 뒤 원문을 그대로 돌려준다 |

## 종료 조건

- 성공: 조건마다 출처가 달린 최종 프롬프트와, 있으면 열린 빈칸 목록을 출력했다.
- 기권: 기권 신호에서 원문·떠올린 순간·아직 말이 안 된 것을 돌려줬다.
- 범위 밖: 원문을 그대로 돌려주고 이유를 한 줄로 알렸다.
